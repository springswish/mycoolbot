Privacy Policy for my cool bot

Last Updated: September 7, 2026

my cool bot (referred to as the “Bot”) is a private Discord bot created for selected clients and approved enterprise servers. It provides features such as leveling, welcome messages, server utilities, and other server-specific functions.

Information We Process

The Bot may process limited Discord information such as:

  • User IDs, usernames, and display names
  • Server, channel, and role information
  • Member join and leave information
  • Message activity and message content where needed for Bot features
  • XP, levels, rankings, and Bot settings
  • User status or activity information where required

How Information Is Used

Information is used only to operate and maintain the Bot and provide its configured features.

The Bot does not sell user information, use it for advertising, or intentionally send user information outside of Discord for unrelated purposes.

Some information, such as XP, levels, and server settings, may be stored so the Bot can function properly.

Message content is not intended to be permanently stored.

Data processed by the Bot is exclusively used within Discord itself.

Data Sharing

Information may be accessible to the Bot operator and authorized server administrators where necessary to operate or manage the Bot for moderation and debugging purposes.

User information is not intentionally shared outside of Discord, except where required by law.

Data Retention and Deletion

Information is kept only as long as reasonably necessary for the Bot’s functionality.

Users may request access to, correction of, or deletion of Bot-specific data where possible by contacting the Bot operators in our Discord server: discord.gg/tylervitelli.

Changes

This Privacy Policy may be updated if the Bot’s features or data practices change over time.
